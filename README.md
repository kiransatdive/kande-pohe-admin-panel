# React Admin Panel

A production-ready, highly scalable React.js Admin Panel using modern frontend development practices.

## Technologies Used
- React.js + Vite
- TypeScript
- React Router DOM
- Redux Toolkit + React Query
- Axios
- React Hook Form + Zod
- Tailwind CSS

## Getting Started

### Prerequisites
- Node.js (v18+)

### Development
1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
2. Setup environment variables:
   Create a \`.env\` file in the root directory and add:
   \`\`\`
   VITE_API_BASE_URL=http://localhost:3000/api
   \`\`\`
3. Start the dev server:
   \`\`\`bash
   npm run dev
   \`\`\`

### Production Build
\`\`\`bash
npm run build
npm run preview
\`\`\`
